# Gemini Draw

A cross-platform desktop app for creating images with Google Gemini. Each task is built from a
set of **reference images** (reorder them by drag-and-drop) plus a prompt, and Gemini generates
the result — downloaded locally so you can preview and save it.

> Uses Gemini's web interface through your browser session. No API key required.

## Features

- Runs on Windows and macOS (built with Tauri 2).
- Per-task reference images with drag-and-drop reordering — the order is sent to Gemini and
  influences the output.
- Live progress for uploads and generation.
- Results are downloaded to your machine and can be previewed, opened in the file manager, or
  saved elsewhere.
- Tasks persist locally between sessions.

## How it works

Gemini Draw does **not** reimplement Gemini's private web protocol. It drives
[`Leechael/gemini-web-cli`](https://github.com/Leechael/gemini-web-cli) as the engine and only
handles process orchestration, file persistence, and the UI:

| What | CLI command |
| --- | --- |
| Sign in | `import` (import browser cookies) |
| Generate image (with references) | `ask --mode image -f ref1 -f ref2 "<prompt>"` |
| Download the result | `download <url> -o <path>` |
| Diagnose account / models | `status` |

All protocol details (batchexecute, StreamGenerate, resumable uploads, cookie refresh) are
maintained upstream, so this repo stays small and robust. Authentication reuses your browser's
signed-in session via cookies — **no API key needed**.

### Tech stack

- **Tauri 2 + Rust** — process orchestration, file & task persistence, thumbnails.
- **React 18 + TypeScript + Vite** — UI.

## Getting started

```bash
npm install
npm run tauri dev
```

On first launch you need to do two things:

1. **Install the engine.** Open Settings → "Install / Update", which downloads the
   `gemini-web-cli` build for your platform from GitHub Releases into the app data directory.
   You can also point it at an existing binary manually.
2. **Import your cookies.** Open <https://gemini.google.com> in your browser and sign in →
   DevTools → Network → pick any request to `gemini.google.com` → copy the entire `Cookie`
   request header → paste it into Settings to import. (You need at least `__Secure-1PSID`;
   `__Secure-1PSIDTS` is recommended.)

Then use "Check account status" to confirm you're signed in, and you're ready to generate.

## Usage

- Tasks are managed on the left; each task has a title, a prompt, a list of reference images,
  and its generated results.
- Reference images: click to pick, drag files from your file manager into the window, or drop
  them onto the reference area. **Drag cards to reorder** — the order is sent to Gemini as-is
  and affects the result.
- "Generate" shows live upload and generation progress, then downloads the full-resolution
  image into the local output folder.
- Results can be enlarged, saved as, or revealed in the file manager.

## Building

```bash
# Windows (on the current machine)
npm run tauri build

# macOS
npm run tauri build -- --target aarch64-apple-darwin   # Apple Silicon
npm run tauri build -- --target x86_64-apple-darwin    # Intel
```

macOS builds must run on a Mac (or cross-compile from macOS), because Tauri needs to link
against the macOS SDK.

App icons are generated by `scripts/make_icons.py` (pure standard library, no Pillow required):

```bash
python scripts/make_icons.py
```

## Project structure

```
src/                      Frontend (React + TS)
src-tauri/src/
  engine.rs               gemini-web-cli bridge: locate, run, parse output, auto-install
  commands.rs             Tauri commands
  paths.rs                App data directory layout
  model.rs                Config & task models
scripts/                  Helper scripts (icon generation, etc.)
```

App data directory:

- Windows: `%APPDATA%\gemini-draw`
- macOS: `~/Library/Application Support/gemini-draw`

It contains `cookies.json` (session), `tasks.json` (tasks), `refs/` (reference image copies),
`output/` (results), and `bin/` (the CLI engine).
